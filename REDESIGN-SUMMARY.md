## 🎓 Presentation Notes

### Key Design Decisions

1. **Gold Accent Color** - Chosen for elegance and luxury feel
2. **Dark Theme** - Better for photography portfolios (makes images pop)
3. **Glassmorphism** - Modern trend, adds depth and sophistication
4. **Animations** - Enhance engagement without overwhelming
5. **Typography** - Serif for elegance, sans-serif for readability

### React Concepts Demonstrated

- **useState** - For filters, quantities, form data
- **useEffect** - For scroll detection
- **Controlled Components** - All form inputs
- **Conditional Rendering** - Menu, empty states, availability
- **Custom Hooks** - useLocalStorage for persistence
- **Component Composition** - Clean, reusable components
